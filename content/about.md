I'm Alessio, a backend engineer in Turin, Italy. I like to own a system across its whole life: designing it, building it, shipping it, then watching how it performs in production and improving it as it goes.

## What I do

I'm a software engineer at AROL, where I own the backend of a customer-facing platform for AROL's clients. It started as the proof of concept for my master's thesis. I then designed and built the real thing in C#/.NET on Azure, and it goes to production soon.

Owning the backend means the work doesn't stop at the code:

- **Shipping.** Releases used to be built by hand and copied onto servers, with no way back. Now they go through tag-based pipelines on GitHub Actions, with smoke tests and health checks that roll a failed release back automatically.
- **Observing.** Traces, metrics and logs are instrumented with OpenTelemetry and sent to Grafana, so I can see what the system is actually doing.

## What I'm building

In my own time I write Go. I like that it pushes toward simple code: a small language that leaves little room for clever abstractions, so code stays easy to read months later. It's also the language behind much of the tooling I use every day, like the OpenTelemetry Collector and Loki.

I'm building [GrepDocs](/projects/grepdocs/), a tool to search and edit documentation across Git repositories. It's also where I practice the side of the job around the code: when it's ready, I'll deploy it publicly and run it myself, with the same care for releases and observability. Most posts here will come from decisions I make along the way.

I'm also part of the [B-AROL-O Team](/projects/b-arol-o/), an open-source group that builds robots for hackathons.

## Where I'm heading

I'm a backend engineer first, and I'm extending what I know toward DevOps, reliability and platform engineering: observability, delivery, and systems that have to hold up under real load. Right now I'm reading _Designing Data-Intensive Applications_ by Martin Kleppmann.

- **Observability:** OpenTelemetry, Grafana
- **Cloud:** Azure
